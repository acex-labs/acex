title: Nodes say whether the collection agent can reach them
---
A collection agent reports the result for each node after a round to `POST /api/v1/inventory/collection_agents/{id}/results`. A node then carries `collection` in the node list and on the node: `ok` or `failing`, the time of the last attempt and of the last successful collection, since when it has failed, how many times in a row, the category and message of the last failure, and the id and name of the collection agent that made the last attempt. An uploaded configuration counts as a successful collection; it does not say which agent made it, so the agent that reported last stays. The node list can be filtered on `collection_status` (`ok`, `failing` or `unknown`, for nodes no agent has reported on yet) and on `collection_agent_id`. `GET /api/v1/inventory/collection_agents/{id}/collection` says how many of the nodes that agent made the last attempt on were collected and, for the others, how many failed for each reason. Run the migration to add the table.
