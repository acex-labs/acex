title: Two Waystream switches can be added as assets
---
Waystream is offered as a vendor when an asset is created, with two models declared: `MS4026-AC` and `MS7048-AC`, both on iBOS. The names come from `show version` on a device and in a report; no port layout is declared for either, because none of the sources states one, so a model has no ports until someone adds them. Every iBOS version seen so far is accepted, for example `6.3.0-ED-R`, `6.3.5-ED-R`, `7.5.2-ED-R` and `7.6.2-GD-R`. There is no Waystream driver in this release, so no model is supported by a NED.
