---
kind: added
title: MAC table, ARP, routes, traceroute and interface status as actions
---
Cisco IOS and IOS XE devices can now run seven more actions: read the MAC
address table or look up one address, read the IPv4 routing table or look up
the route to an address or prefix, read the ARP table or look up one address,
trace the route to a target, and read interface status with speed, duplex,
errors and discards. Interface names are reported as the device writes them.
