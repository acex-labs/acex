# Examples

Worked examples showing common ACE-X configuration patterns.

Each example is a self-contained ConfigMap directory with an `app.py` and one or more config maps under `config_maps/`.

| Example | What it shows |
|---------|---------------|
| [example1](https://github.com/acex-labs/acex/tree/main/docs/examples/example1) | Basic setup — loopback interface, NTP |
| [example2](https://github.com/acex-labs/acex/tree/main/docs/examples/example2) | Variable parameters from logical node attributes |
| [example3](https://github.com/acex-labs/acex/tree/main/docs/examples/example3) | External datasource lookup (IPAM) |
| [example4](https://github.com/acex-labs/acex/tree/main/docs/examples/example4) | VLANs and network instances |
| [example5](https://github.com/acex-labs/acex/tree/main/docs/examples/example5) | LAG / port-channel configuration |
| [example6](https://github.com/acex-labs/acex/tree/main/docs/examples/example6) | SNMP configuration |
| [example7_driver_discovery](https://github.com/acex-labs/acex/tree/main/docs/examples/example7_driver_discovery) | NED driver discovery and selection |
| [example8](https://github.com/acex-labs/acex/tree/main/docs/examples/example8) | ACL configuration |
| [example9](https://github.com/acex-labs/acex/tree/main/docs/examples/example9) | STP configuration |
| [example10_system_settings](https://github.com/acex-labs/acex/tree/main/docs/examples/example10_system_settings) | System-level settings (hostname, contact, location) |
| [example11_static_route](https://github.com/acex-labs/acex/tree/main/docs/examples/example11_static_route) | Static routing |
| [example12_banner](https://github.com/acex-labs/acex/tree/main/docs/examples/example12_banner) | Login and MOTD banners |
| [example13_aaa](https://github.com/acex-labs/acex/tree/main/docs/examples/example13_aaa) | AAA (TACACS+, RADIUS) |
| [example14_cisco_augments](https://github.com/acex-labs/acex/tree/main/docs/examples/example14_cisco_augments) | Cisco-specific augmentations |
| [example15_auth](https://github.com/acex-labs/acex/tree/main/docs/examples/example15_auth) | SSH authorized keys |
| [AI Ops](ai_ops.md) | AI Ops — providers, models, and failover chains |
